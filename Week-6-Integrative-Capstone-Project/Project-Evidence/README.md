# Project Evidence & Outputs

This folder contains supporting evidence for the Week 6 Integrative Capstone Project.

## Recommended contents

Upload the generated project evidence here, including:

- EDA graphs and visualization PNG files
- K-Means / clustering graphs
- PCA visualization
- Model performance graphs
- Confusion matrices
- ROC and Precision-Recall curves
- Threshold analysis plot
- Feature coefficient / feature-importance plots
- Important CSV result tables
- Model comparison results
- Cross-validation results
- Error-analysis CSV files
- Cluster profiles and segment results
- Insight and recommendation tables
- Reflection, limitation, and improvement evidence
- Any other final proof files that support the report

## Suggested organization

You may keep the files directly in this folder, or organize them into subfolders:

Project-Evidence/
├── EDA/
├── Feature-Engineering/
├── Segmentation/
├── Churn-Prediction/
├── Model-Validation/
├── Error-Analysis/
├── Insights/
└── Reflection/

The final report should remain in the main Week 6 folder. This evidence folder is for supporting outputs and proof of the end-to-end project work.

## Source

All files in this folder should be generated from the Week 6 capstone notebook and the corresponding analysis pipeline.
