## Week 1 — Data Acquisition, Cleaning & Preprocessing

### Project: Titanic Dataset Analysis

Week 1 focuses on acquiring a dataset, assessing its quality, cleaning and preprocessing the data, identifying outliers, and preparing datasets for subsequent analysis and machine-learning workflows.

### Work Completed

- Loaded and inspected the Titanic dataset
- Examined dataset dimensions, columns, and data types
- Identified missing values and their proportions
- Handled missing values using imputation where appropriate
- Removed a column with excessive missingness
- Detected and removed duplicate records
- Standardized categorical text values
- Generated descriptive statistics
- Identified potential numerical outliers using the IQR method
- Applied IQR-based capping to selected numerical variables
- Performed encoding and numerical feature scaling for preprocessing
- Created preliminary visualizations
- Performed final data-quality checks
- Exported cleaned and preprocessed datasets

### Week 1 Files

- `Yuva_Week1_Titanic_Data_Cleaning.ipynb` — Python notebook containing the project workflow
- `titanic_cleaned.csv` — cleaned dataset
- `titanic_preprocessed.csv` — preprocessed dataset prepared for analysis/modeling
- `Yuva_Week1_Titanic_Data_Cleaning_Report.docx` — documented project report with supporting evidence

### Learning Outcomes

Through this task, I gained practical experience in data quality assessment, missing-value handling, duplicate detection, categorical-data standardization, descriptive statistics, IQR-based outlier treatment, feature encoding, numerical scaling, visualization, and preparation of datasets for machine-learning workflows.
